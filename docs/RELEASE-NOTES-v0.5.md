# Guitar Edition 0.5 - UI, IR waveform and microphones

- Rule 1: source strings are UTF-8; preflight rejects known mojibake patterns and corrupted replacement glyphs.
- Rule 2: calculated component bounds are tested at five editor dimensions for every page, including minimum dimensions.
- Two embedded studio amplifier/cabinet images plus real WAV-derived previews.
- Two draggable XY microphone positions linked to independent automatable controls.
- Choice of six microphone families, with clearly labelled **post-IR** timbral simulation.
- Processing remains after existing convolution to avoid falsely claiming physical microphone reconstruction.
- Windows and macOS CI compile still required; all audio pathways must be tested manually.
